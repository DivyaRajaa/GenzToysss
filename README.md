# GenzToysss

A full-stack Toy Shopping Web Application developed using Java Servlet, JSP, JDBC, and MySQL.

## Technologies Used

- Java
- Java Servlet
- JSP
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- Apache Tomcat

## Features

- User Registration and Login
- View Available Toys
- Add Toys (Admin)
- Edit and Update Toys
- Shopping Cart
- Order Management
- Database Connectivity using JDBC

## Project Structure

- Model - Data classes
- DAO - Database operations
- Controller - Servlets
- Web Content - HTML, JSP, CSS, Images
